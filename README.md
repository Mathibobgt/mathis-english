# Mathis English

Appli d'anglais de Mathis (Erasmus Győr 2026–27), installable sur iPhone et utilisable sans réseau.

- Site : https://mathis-english.netlify.app
- Chaque envoi sur `main` est publié automatiquement par Netlify.
- Hors-ligne : `sw.js` garde la page, les polices et les icônes dans le téléphone. Changer `CACHE` dans `sw.js` quand les polices ou icônes changent.
- Progression : enregistrée dans le téléphone (localStorage), exportable avec « Copier mon bilan ».
